# FaceVision 项目验收说明

## 1. 项目目标

本项目实现一个基于 Qt 6 与 OpenCV 的桌面人脸识别系统，覆盖数据采集、人脸检测、特征提取、人员注册、身份识别、数据库管理和识别记录的完整流程。

## 3. 建议演示顺序

1. 打开程序，说明系统自动检查模型和数据库；
2. 导入一张单人人脸图片，展示“陌生人”；
3. 点击注册，输入编号、姓名和部门；
4. 再导入同一人的不同图片，展示识别姓名和相似度；
5. 进入人员管理，展示人员 CRUD、多样本和批量导入；
6. 启动摄像头，展示实时框选、动态状态和框平滑；
7. 使用多人画面展示多人脸检测；
8. 双击识别日志查看抓拍；
9. 说明小型人脸库使用精确矩阵检索，大型库自动切换 KD 树；
10. 展示 `data` 目录中的数据库、样本和日志持久化结果。

## 4. 答辩要点

### 为什么选择 YuNet 和 SFace

YuNet 能直接输出人脸框、五个关键点和置信度，适合实时应用；SFace 提供统一的人脸对齐与特征提取接口，能够得到固定长度的 128 维特征。两者均可通过 OpenCV API 直接部署，不需要额外深度学习框架。

### 为什么一个人要保存多张样本

单张样本容易受角度、表情和光照影响。多样本既保留最相似样本，也可以计算中心特征，从而提高识别鲁棒性。

### 为什么使用余弦相似度

人脸特征经过 L2 归一化后，余弦相似度等价于比较特征方向，受向量整体尺度影响较小，适合高维特征匹配。

### 为什么日志不能每帧都写

摄像头每秒会处理多帧。逐帧写入会产生大量重复记录，因此系统把“人员进入画面”视为一次事件，并设置冷却时间。

### 动态活体辅助的边界

当前模块基于连续帧的运动、尺度和关键点变化，只用于课程演示和初步提示。真实高安全场景需要专用活体模型、深度摄像头或红外设备。
